# GeoCam - How to Run

## Option 1: Install the APK directly on your Android phone (No Flutter required)
1. Send `apk/geocam.apk` to your phone (via WhatsApp, Google Drive, or USB).
2. Tap the `.apk` file on your phone and choose "Install" (enable "Install unknown apps" if prompted).
3. Open **GeoCam** and grant Camera, Audio, and Location permissions.

---

## Option 2: Run from Source Code (Flutter)
If you want to run or modify the code on your computer:
1. Open this folder in your terminal or IDE (VS Code / Android Studio).
2. Connect your Android phone (with USB Debugging enabled) or start an emulator.
3. Run:
   ```bash
   flutter pub get
   flutter run
   ```
